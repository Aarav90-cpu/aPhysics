# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please do not file a public issue.

Instead, please report security vulnerabilities via GitHub Security Advisories or by contacting the maintainers directly.

Please include:
- A description of the issue and potential impact
- Steps or proof-of-concept code to reproduce the issue
- Affected configurations, platforms, or compilers

Maintainers will acknowledge receipt within 48 hours and coordinate remediation before public disclosure.
